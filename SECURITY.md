# Security Policy

## Reporting a Vulnerability

Do not open a public issue for vulnerabilities. Report to <charles@farfa.tech>
Include: description + impact, affected versions/platforms, reproduction if any.
Expect acknowledgement within a few days. Coordinated disclosure and credit; fix and advisory published once a patch is ready.

## Scope

UUIDv7 library in this repository.

Out of scope: Dependencies or workspace (e.g. Criterion, C, clang, docker, test, makefile...)
